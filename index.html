六个关键概念

黎曼几何的主线：先给出度量，再由度量推出测地线、曲率和它们的一切后果。

度量张量gij

在每一点规定怎样量长度和角度，几何就从这里开始。本页画布的度量是 ds² = (dx² + dy²) / (1 + K(x² + y²)/4)²。打开“等大小圆”图层：这些小圆的真实半径完全相同，画出来却大小不一，因为度量在逐点变化。

测地线geodesic

局部最短的曲线，是“直线”在弯曲空间里的推广。在这个画布模型中，测地线总是画成圆弧或直线。它们看起来弯，是投影造成的；在空间内部走，它们一点也不拐弯。

曲率是内蕴的Theorema Egregium

高斯曲率只依赖度量，不依赖曲面怎样放在外部空间里。纸卷成圆柱，曲率仍是 0；球面怎么弯折都压不平。住在曲面里的人量一量小圆的周长，就能算出 K。

高斯–博内定理Gauss–Bonnet

测地三角形的角盈等于它围住的总曲率：Σ − π = ∬K dA。局部的曲率与整体的角度、乃至曲面的拓扑（欧拉示性数）被一个等式连在一起。

平行移动与和乐holonomy

沿一条路径“不转动”地搬运向量，这由联络规定。在弯曲空间里绕一圈回来，向量会转过一个角度，大小正是回路围住的总曲率。曲率可以理解为平行移动对路径的依赖程度。

雅可比方程geodesic deviation

相邻测地线的间距 J 满足 J″ + K·J = 0。正曲率像引力一样把测地线拉拢，负曲率把它们推散。广义相对论中的潮汐力就是这个方程在四维时空里的版本。

画布使用曲率为 K 的共形模型（球极投影型）：K > 0 时是球面从对径点投影到平面，整个球面铺满画布；K = 0 时就是普通平面；K < 0 时是半径 2/√−K 的庞加莱圆盘。这个模型如实保留角度，长度则被拉伸：离中心越远，球面上的东西画得越大，双曲平面上的东西画得越小。

所有读数都由程序实际测量：角度取自测地线切方向，长度和面积对度量做数值积分，再与理论公式比较。
